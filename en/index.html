FAQ

Can I get banned?

Forge only changes the game's settings files, the same thing that happens when you move sliders in its menu. It never interferes with the game's memory or processes. Before writing, it asks you to close the game so the game doesn't overwrite the files on exit.

How many FPS will I get?

It depends on the hardware and the game, so Forge promises nothing. It explains what each setting does, and the game itself shows FPS before and after: in Rust, for example, console F1 → perf 1.

Do I need an account?

You can download Forge and use the free features without an account. A subscription needs a sign-in with a code sent by e-mail.

What if something goes wrong?

Every change can be undone in “Settings → History and backups”, and Forge makes a restore point before Windows tweaks. If you need help, message support on Telegram.

What are the system requirements?

Windows 10 or 11, 64-bit. About 150 MB of disk space. Forge installs everything else itself.
